# Code of Conduct

IBVAP is built by a small team under deadline pressure. Pressure is when conduct matters most.

## Our standard

- **Respect.** Treat every contributor as a capable colleague. Disagree with the code or the idea, never the person.
- **Be specific and kind in reviews.** Say what to change and why. No sarcasm, no public shaming, no "obviously".
- **Ask early.** Asking a question is expected, not a weakness. Nobody is expected to know everything; everyone is expected to say when they are stuck.
- **Share credit, own mistakes.** Broken builds happen. Report them quickly and fix them without blame.
- **Be inclusive.** No harassment, discrimination, or demeaning language of any kind, in code, comments, commit messages, issues, PRs, or chat.
- **Respect time and rest.** Do not pressure teammates to work unreasonable hours; flag risk early so the plan can change instead.

## Responsible use of this project

IBVAP is a surveillance-analytics prototype. Contributors agree to:

- Use only consented footage (team members) for testing and demos; never commit real individuals' images or video.
- Keep the system human-in-the-loop: AI raises alerts, people decide.
- Report accuracy honestly. Do not present unmeasured numbers as results, and state limitations plainly.
- Not use the code or data for stalking, harassment, or any unlawful surveillance.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory remarks, deliberately sabotaging another person's work, committing others' private data, or misrepresenting results.

## Enforcement

Report concerns to the repo owner (Divyansh) or, if the concern involves the owner, to any other team member or the team's faculty mentor. Reports are handled respectfully and privately. Possible outcomes: a conversation, a request to change behaviour, or removal of repository access.

## Scope

Applies to the repository, pull requests, issues, team chats, and any event where the team represents IBVAP.
